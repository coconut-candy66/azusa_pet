# 开发路线图

返回 [项目首页](../README.md) · [技术说明](technical-notes.md)

下列为后续开发方向，不代表已经实现或已安排执行。

## 当前状态

| 模块 | 状态 |
| --- | --- |
| 桌面容器 | 已有透明置顶、点击穿透、拖拽与右键退出 |
| 立绘 | 5 套服装、15 张 PNG；当前仅显示每套 idle |
| 交互 | 点击换装，每轮不重复，相邻两次不同 |
| 动画 | 呼吸、摇摆、浮动；不实现眨眼 |
| 情绪 | 有 mood 数值及衰减，尚无完整状态机 |
| 对话与记忆 | 未实现；现有气泡为预设台词且默认关闭 |
| 素材清理 | 2026-09-17 完成透明边缘清理与遮罩更新 |

## 优先方向一：行为状态

在现有 mood 基础上评估精力、亲密度、静置和连续点击反应。将状态转移设计为可独立测试的纯逻辑，渲染层负责表现。先确认规则，再增加视觉效果。

## 优先方向二：对话与记忆

后续可接入模型 API、角色设定、流式气泡及历史交互记录。模型凭据应与经常修改或分享的桌面配置分开存放。涉及网络请求与数据保存时，再明确相应开关和保存范围。

## 可选方向：新服装与表情

新增服装沿用当前透明 PNG 与离线遮罩流程。若增加表情，先准备姿势、取景和脚底位置一致的素材，避免恢复整身闪动问题；局部叠加效果也应单独评估。

素材处理与测试命令见 [开发说明](../deskpet-demo/README.md)。原路线图已备份到 `art/backups/2026-09-17-before-organization/下一步做什么.md`。
