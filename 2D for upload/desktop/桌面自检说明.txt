桌宠启动不了？按这三步走
================================================

第 1 步：双击  _启动自检.cmd

    · 如果窗口停住并显示「自检通过」  -> 系统没问题，继续第 2 步
    · 如果它也是一闪就没           -> 你的系统本身有问题，
                                      把这个情况告诉我，先别往下走

第 2 步：双击  调试启动.cmd

    这个脚本会把黑框窗口留住，里面滚动显示运行日志。
    如果启动失败，窗口里会留下报错内容 —— 把那段内容发给我。

    · 如果窗口留住但没报错      -> 继续第 3 步
    · 如果窗口里出现 GPU 字样   -> 改用第 3 步

第 3 步：双击  兼容模式启动.cmd

    它强制用 CPU 画图，不依赖显卡。显卡驱动有问题时这一招最有效。
    代价是画面会慢一些、更费电，所以平时还是用 启动桌宠.cmd。


顺带说明：这次闪退的原因已经找到并修好了
================================================

三个 .cmd 之前被存成了 UTF-8 编码 + LF 换行，而 cmd.exe 需要的是
GBK 编码 + CRLF 换行。写错的后果不是「报个编码错误」，而是脚本跑到
一半就静默退出 —— 也就是你看到的「一闪就没了」。

现在已经全部改成 GBK + CRLF，并删掉了脚本里那句会中途切换编码的
chcp 命令。另外还给启动脚本加了「存活检查」：启动后它会等 2 秒确认真
的起来了，起不来就把原因打印出来并停住，不会再让你对着一个闪过的黑
框发呆。

这三个文件以后如果你想自己改，请用 Windows 自带的记事本，另存为时
编码选「ANSI」。不要用 VS Code 之类的编辑器，它们默认存 UTF-8 + LF，
会把这个 bug 重新带回来。

_启动自检.cmd 和这份说明都是临时诊断用的，问题解决后可以直接删掉。
