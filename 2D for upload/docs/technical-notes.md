# 技术说明

返回 [项目首页](../README.md) · [开发与测试命令](../deskpet-demo/README.md)

本文记录当前实现约定。路径未特别说明时，以 `2D/deskpet-demo` 为基准。

## 窗口与渲染

主进程负责透明窗口、置顶、点击穿透、拖拽及配置重载；渲染进程使用 DOM 与 CSS transform 显示 PNG，并负责动画与命中计算。配置通过 preload 的受限接口进入页面。

用户配置仅从 `DESKPET_CONFIG` 指定位置读取，由 `desktop` 下启动器设置。未设置时使用内置默认值。默认配置与桌面用户配置不是同一套效果，运行截图测试时须明确选择。

## 坐标约定

`#pet` 为零尺寸元素，原点位于立绘脚底中线。局部坐标为：

```text
x ∈ [-W/2, W/2]
y ∈ [-H, 0]
屏幕坐标 = R(旋转) × S(缩放) × 局部坐标 + 锚点
```

命中检测使用同一变换的逆运算 `screenToLocal`。维持一套坐标定义，避免显示与点击范围分离。几何测试对正变换再反变换进行校验。

## 透明轮廓与点击遮罩

PNG 负责视觉透明度；`mask.json` 负责点击区域。运行时不通过 canvas 读取本地 PNG 像素，遮罩由离线工具从 alpha 通道降采样生成。

遮罩包含 `w`、`h`、`bits` 等字段。`bits` 为 Base64 编码的连续位流，按行排列，字节内 MSB 优先，行尾不补齐。素材工具可将其解码后与降采样结果逐点核验。

贴图模式查询遮罩，矢量模式查询绘制形状的并集。遮罩缺失时可由 `hit.fallbackToBox` 回退到矩形。`debug.showHitMask` 应显示真实判定结果，不能维护另一套近似几何。

## 换装

换装列表使用洗牌发牌。一轮内不重复，重新洗牌时避开当前套装，确保相邻两次点击不同。素材加载完成后才应用新套装；更新宽高比、摆位样式和遮罩应保持一致。

当前仅显示各套 `idle.png`。开心与惊讶图是不同姿势的全身立绘，不能作为同一姿势的表情帧直接切换。

## 为什么不做眨眼

历史上尝试过换图眨眼、叠加眼睑和压缩眼部区域。换图因整身姿势不同产生闪动；局部图层处理也曾引入整个人物缩放异常。当前实现已移除眨眼图层与配置。

保留的行为是呼吸、摇摆、浮动和点击换装；仅换装时改变立绘来源。`tests/smoke/no-blink.js` 同时检查静置不换图、点击能够换图及渲染循环仍在运行。

## 测试经验

- 隐藏窗口中的动画帧会降频。涉及渲染进度时等待帧数，或使用调试接口冻结状态，不依赖一次固定延时。
- 检查短暂点击效果前固定状态并清零反应值，避免时序碰巧决定结果。
- 换装应检查相邻两次不同、牌堆无重复、按轮分组无重复，而非要求任意连续多次截图永不重复。
- 高 DPI 下尺寸可能有 1 像素取整差异。区分一次取整与持续漂移。
- 验证周期动画的漂移应比较一段采样的均值，不能只比较两个可能处于不同波峰的瞬时值。
- 截图统计应排除 HUD；元素实际有面积后，才能判断是否在窗口内。
- 像素统计、命中测试和截图检查各有用途，任何一项通过都不能代替另外两项。

## 启动器编码

现有 Windows 启动器采用 GBK 与 CRLF，`.gitattributes` 将 `.cmd` 标记为 `-text` 以保持原始字节。修改脚本时保留编码与换行，避免引入与本机现有脚本不一致的代码页切换。
